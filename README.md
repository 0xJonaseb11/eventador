# Eventador

Staff landing page for Event Staff and Vendors. People in NYC 5 Boroughs and Long Island sign up for work at local parties and events. Businesses can view a profile and get in touch.

## Run

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 4173
```

Then open http://127.0.0.1:4173

## Files

- `index.html` page
- `styles.css` layout
- `assets/` photos

No packages and no build step.
